# 首轮实机测试清单

目标环境：Windows 10/11 x64、OBS Studio 32.2.2、iPhone 与电脑同一专用网络。

## 安装与发现

- [ ] Bonjour 服务正在运行
- [ ] 原版 uxplay-windows 已退出
- [ ] OBS 为 32.2.2，宿主 FFmpeg 文件版本为 n8.1.2
- [ ] 插件目录没有重复的 avcodec/avutil/swscale/swresample DLL
- [ ] OBS 能加载“iPhone 投屏接收器（AirPlay）”
- [ ] “工具”菜单显示“iPhone 投屏控制台（AirPlay）…”，点击后在当前场景创建/复用来源并打开状态窗口
- [ ] 未连接时画布显示等待页、接收器名称和投屏步骤
- [ ] 等待页的文字、图标和圆角卡片每次都完整显示，不会偶发只剩背景
- [ ] 客户端发起连接后显示设备名称/型号，首个视频帧能替换状态页

- [ ] iPhone 的“屏幕镜像”列表能看到设置的名称
